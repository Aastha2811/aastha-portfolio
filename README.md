# Aastha Gupta · Product Manager portfolio

A single-page portfolio: case studies, how I work, an interactive toolkit and a recruiter fit check.

Plain HTML, CSS and JavaScript with no build step. Fonts load from Google Fonts.

## Run locally

Open `index.html` in a browser, or serve the folder:

```
python3 -m http.server 8000
```

## Hosting

Served by GitHub Pages from the `main` branch root.
